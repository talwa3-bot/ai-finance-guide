# AI Finance Studio

עורך וידאו ותוכן בדפדפן לקהילת AI Finance.

## מה יש כאן
- `index.html`, `style.css` - מבנה ועיצוב
- `engine.js` - מנוע: מדיה, קומפוזיציה על קנבס, קי-פריימים, אודיו, ייצוא
- `ui.js` - ציר זמן, חלונית עריכה, טקסט, כתוביות, מותג
- `ai.js` - במאי: יצירת סרטון מרעיון, עריכת תוכן, ביקורת, טרנדים
- `assets/` - הלוגו

## הרצה
העמוד סטטי. יכולות הבינה (יצירה, עריכה, ביקורת) והשמירה לקובץ פועלות כשהעמוד מפורסם כארטיפקט בקלוד.
לפתיחה מקומית בלי בינה: `python3 -m http.server` ואז `http://localhost:8000`.

## שמירת שתיקות
העלאת וידאו או אודיו שומרת את כל הקליפ, כולל שתיקות. הכפתור ״הסרת שתיקות״ מציג תחילה את משך ההסרה ואת אורך הקליפ לפני ואחרי. רק אישור נפרד מבצע את החיתוך. ביטול, Escape או לחיצה מחוץ לחלון משאירים את הפרויקט ללא שינוי. אם הפרויקט השתנה בינתיים, יש לבדוק ולאשר מחדש. אפשר להחזיר הסרה מאושרת באמצעות ״בטל״.

## בדיקות
בדיקות רגרסיה ללא תלויות נוספות, עם Node.js 18 ומעלה:

```sh
node --check studio/engine.js
node --check studio/ui.js
node --check studio/ai.js
node --test studio/tests/silence.test.cjs
```

מריצים משורש המאגר. הבדיקות מריצות את קוד הבקר האמיתי עם הדמיה של הדפדפן ופענוח המדיה; הן אינן בדיקה חזותית או בדיקת פענוח קובץ אמיתי. הן מכסות העלאה ללא חיתוך, תצוגת משך, ביטול, Escape, מיקוד מקלדת, אישור חד־פעמי, שינוי פרויקט בזמן התצוגה, מהירות קליפ וביטול העריכה.

בדיקה ידנית בדפדפן: להעלות סרטון עם קטעים שקטים, לוודא שאורכו נשמר, לפתוח ״הסרת שתיקות״ ולבטל, לפתוח שוב ולאשר, ואז ללחוץ ״בטל״ ולוודא שהקליפ המקורי חזר. יש לבדוק גם תצוגת נייד וניווט עם Tab ו־Escape.
