# AI Finance Studio

עורך וידאו ותוכן בדפדפן לקהילת AI Finance.

## מה יש כאן
- `index.html`, `style.css` - מבנה ועיצוב
- `engine.js` - מנוע: מדיה, קומפוזיציה על קנבס, קי-פריימים, אודיו, ייצוא
- `ui.js` - ציר זמן, חלונית עריכה, טקסט, כתוביות, מותג
- `ai.js` - במאי: יצירת סרטון מרעיון, עריכת תוכן, ביקורת, טרנדים
- `assets/` - הלוגו

## הרצה
העמוד סטטי. יכולות הבינה (יצירה, עריכה, ביקורת) והשמירה לקובץ פועלות כשהעמוד מפורסם כארטיפקט בקלוד.
לפתיחה מקומית בלי בינה: `python3 -m http.server` ואז `http://localhost:8000`.
